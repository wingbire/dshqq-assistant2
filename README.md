# DSH-QQ 群小助手

常驻 QQ 群的**有性格的小助手**：本地算法先判断「这条消息是不是对我说的」，再决定**说不说 / 说多深 / 要不要先搜 / 配不配图**；只有必要时才调用大脑（DSH agent preset），并把人设常驻在系统提示词最前段以吃满前缀缓存；回复后按「被回复人有没有继续跟它聊」自学习，逐渐贴合本群兴趣与习惯。

> 状态：**实现完成，待接真实 QQ**。回归测试 150 项全过，全量验收 8/8。

## 快速开始

    # 1. 起程序（默认「新群先观察」：只判定、一个字都不发）
    node app/main.js

    # 2. 浏览器进配置端（人设 / 判定 / 接入 / 标注 / 图库 都在这里改）
    http://127.0.0.1:8799

    # 3. 想省事就用托盘启动器（自己找 node、自己起、自己开浏览器）
    launcher\DSHQQTray.exe

    # 自检
    node test/run-tests.mjs          # 150 项
    node demo/run-acceptance.mjs     # 全量验收记分卡

## 需要你自己准备的三件

| 东西 | 为什么 |
|---|---|
| **DeepSeek API key** | BYO key：每位使用者用自己的账号付费。写进 `app/dsh-data/config/secrets.json`（gitignored），或跑 `node demo/import-key.mjs` 从本机既有 DSH 凭据导入一次 |
| **NapCat / OneBot v11** | 收发 QQ 群消息。WS 地址与令牌填进配置端「接入」页 |
| **表情包图库（可选）** | 内置那套图库授权是 personal，不能随程序分发。自己攒一套放 `app/meme-lib/<情绪标签>/*.jpg` 即可，没有也能跑（只是不配图） |

## 它会怎么行事

    新群：先观察 80 条（只判定、不发送） → 半自动 3 天（只回被点名的） → 全自动（能在感兴趣的话题插一句）

刹车有三条：群内 `/停` `/开` `/状态`（群主/管理/白名单）、配置端暂停、安装目录放一个 `STOP` 文件即全局停。
外审、搜索、识图都是**独立的额外调用**，可以分别关掉。

## 边界

- 群聊数据**只在本机**；除调用模型 / 搜索 / 识图所必需的片段外不外传，没有遥测
- **群聊原文不落盘**（只存关键词与统计；标注队列存 ≤40 字摘要）
- 凭据只存 `app/dsh-data/config/secrets.json`，永不回给前端
- 分发版打包带双闸门：不含任何密钥、图库素材、开发者私史、运行期数据

上线前请确保群主与管理员同意，并让群里的人知道有个机器人在听。
