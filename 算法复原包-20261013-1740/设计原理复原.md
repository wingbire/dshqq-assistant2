## 二、核心：统一效用 U（六因子）

```js
// utility.js 头部原文
// 收益层（越高越值得说）：
//   ① 对象判断 p_say    —— 这句话是不是在对我说（addressee 置信度）
//   ② 语义理解 v_sem    —— 和上一条/当前话题的语义相关度 + 是否带来新信息
//   ③ 对话延续 v_cont   —— 我在这轮对话里的位置（被直接回复 / 刚说完 / 群里在聊我 / 全新话题）
//   ④ 需求判定 v_demand —— 这句话要不要人回应（demandScore 归一化）
// 成本层（越高越不该说）：
//   ⑤ 回复难度 d_diff   —— 问题类型 + 是否要长内容 + 这类问题历史输出规模（外部可观测量，不让模型自报）
//   ⑥ 预估 token d_cost —— 未命中输入 + 2×输出（与计费口径一致），再按成本量纲归一
```

**公式（原文）**
$$U = (w_1 p_{say} + w_2 v_{sem} + w_3 v_{cont} + w_4 v_{demand}) - \lambda_{eff} \cdot \frac{d_{diff} \cdot d_{cost}}{costScale}$$

**实测常数（取回源码里的字面值）**

```js
export const UTILITY_WEIGHTS = { w1: 0.40, w2: 0.20, w3: 0.25, w4: 0.15,
                                 lambda: 0.5, gateLow: 0.15, gateHigh: 0.5 };
export const TOPIC_DEPTH_K = 0.10;   // 话题深度主效应：0.10/点（0~3 分 → 最多 +0.30）
```
```js
// 实测计算式
const benefit = (W.w1*pSay + gate*(W.w2*clamp01(sem) + W.w3*cont + W.w4*clamp01(demand))) * eng;
const cost    = num(W.lambda, 0.5) * dDiff * (dCost / costScale);
```

**设计取舍（原文三条）**
1. **硬触发地板**：@我 / 回复我 / 叫外号 命中时，U 再低也至少给一句短的 —— 不允许"被点名也不回"（就是式子里的 `gate` 系数, `gateLow/gateHigh`）
2. **同一把尺子**：成本折算成"奖励单位"（λ_eff），让"说不说"和"值不值这个钱"可比
3. **不让模型自报成本**：`d_diff` 只用外部可观测量估计

**三档阈值（决定回复深度）**：`utilitySpeakAt` / `utilityTerseAt` / `utilityDetailedAt`
- 默认 0.10 / 0.30 / 0.60（utility.js 里 `speakAt` 缺省 0.10）
- 项目 `config.js` 实际取 **0.20 / 0.35 / 0.65**，且可按群覆盖
- 代码注释里记了一条 2026-10 的修正：原来是"从高往低先比"，导致把开口线调得比常规线还高时行为异常 → 改成先比开口线

## 三、代价感知评分（score.js）

文件头列了 4 篇设计参考（ICML 2026 的 InteractCS-RL 成本感知 reward、RouteLLM 的质量-成本路由、自适应思考预算、以及"标量化 + 近端探索"的多目标做法），并给出：

```js
lambda: 1.0, alpha: 0.25, beta: 0.8, refN: 20      // 默认参数
const reward = r.engagement - c.lambda * r.norm;   // 互动分 − λ×归一化代价
// cost = (未命中输入 + 2×输出)，与真实计费口径一致（缓存命中的读取记 0）
```

同时用**指数折扣**（更看重最近互动）、**UCB 探索加成**（样本少时推动再试）、**帕累托前沿**（互动分 vs token 效率）避免过早收敛到局部最优。

- 语料与行为统计**每群一份**（`Map<gid, {df, docs, perUser, corpus}>`），在线学习：群里每句话都喂进来更新 IDF 与"接话倾向"

## 五、参数门控 · 话风臂学习（bandit.js）

原文自述：把"同一句话可以短促接梗（便宜）也可以详细解释（贵）"建模成**上下文多臂老虎机**：

| 维度 | 取值 |
|---|---|
| 臂 arm | 话风：`terse` / `standard` / `detailed`（生成成本不同） |
| 上下文 bucket | 消息类型：提问 / 梗与吐槽 / 游戏机制 / 日常闲聊 / 其他 |
| 收益 | 代价感知 reward（score.js） |
| 算法 | **Normal-Inverse-Gamma 共轭 + Thompson Sampling**：σ² ~ Inv-Gamma(aₙ,bₙ) → μ ~ N(μₙ, σ²/κₙ)，取 μ 样本最大臂 |
| 先验 | `PRIOR = { mu: 0, kappa: 1, a: 2, b: 4 }`（弱先验，方差 4 容得下 −2..+4 的 reward） |
| 无依赖实现 | Box-Muller 高斯采样 + Marsaglia-Tsang Gamma 采样，rng 可注入便于测试 |
