## 1. 两个工作区怎么分

| | 开发工作区 | 制作工作区 |
| --- | --- | --- |
| 路径 | `E:\AI视频工作流` ←**你在这里** | `E:\AI视频制作` |
| 放什么 | 程序代码、工具、开发文档 | 各期产物、素材、制作文档 |
| 什么时候用 | 改程序 | 做视频 |

**绑定靠** `config.json`：

```json
{ "paths": { "workspace": "E:\\AI视频制作" } }
```

改这一行就能换制作区位置，**不用动代码**。

代码里的映射（见 `app/lib/env.mjs`）：

| 常量 | 值 |
| --- | --- |
| `ROOT` | `E:\AI视频工作流`（程序目录） |
| `WORKSPACE` | `E:\AI视频制作`（制作区） |
| `PROJECTS` | `E:\AI视频制作\projects` |
| `ASSETS` | `E:\AI视频制作\assets` |

## 4. 怎么用

**起服务**：双击 `启动视频工坊.bat`，浏览器会开一个无地址栏窗口。

**命令行**（在**本目录**执行）：

```
node app/cli.mjs env                  # 环境自检
node app/cli.mjs ls                   # 列出制作区所有期
node app/cli.mjs status 2026-10-10    # 看某期产物状态
node app/cli.mjs all    2026-10-10    # 一条龙
```

> ⚠️ 命令都在**本目录**执行，但读写的是**制作区**的数据。
